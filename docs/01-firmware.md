# Подготовка: прошивка OpenWrt 25.12.6 на Cudy WR3000S v1

Этот документ — про самую рискованную часть: установку OpenWrt на роутер.
Если у вас уже стоит OpenWrt 25.12.x — переходите к `../README.md`.

> **Важно.** Роутер Cudy WR3000S v1 поставляется с заводской прошивкой Cudy,
> которая **не принимает официальный образ OpenWrt напрямую**. Нужен промежуточный
> образ, подписанный Cudy. Порядок ниже — обязательный.

---

## 0. Что понадобится

- Роутер Cudy WR3000S v1, блок питания.
- Компьютер с сетевым портом (Wi-Fi не подойдёт для этапа 2) и браузером.
- Интернет на компьютере (для скачивания образов).
- 20–30 минут времени.
- Желание прочитать этот документ целиком до начала.

Проверьте модель и версию на наклейке снизу: должно быть **WR3000S**, версия **v1**,
и код партии в серийном номере (см. раздел «Новая флеш-память» ниже).

---

## 1. Какая прошивка нужна

Для WR3000S v1 в OpenWrt 25.12.6 есть профиль **`cudy_wr3000s-v1`**
(цель `mediatek/filogic`, архитектура пакетов `aarch64_cortex-a53`).

Файлы (страница: <https://downloads.openwrt.org/releases/25.12.6/targets/mediatek/filogic/>):

| Файл | Назначение |
|------|------------|
| `openwrt-25.12.6-mediatek-filogic-cudy_wr3000s-v1-squashfs-sysupgrade.bin` | основной образ, который вы зальёте на шаге 4 |
| `openwrt-25.12.6-mediatek-filogic-cudy_wr3000s-v1-initramfs-kernel.bin` | для восстановления по TFTP/серийнику (обычно не нужен) |

Проверять SHA256 удобно через страницу **firmware-selector**:
<https://firmware-selector.openwrt.org/?target=mediatek%2Ffilogic&id=cudy_wr3000s-v1>

> **НЕ** берите образ `...-ubootmod-...`, если не собираетесь ставить модифицированный
> загрузчик OpenWrt U-Boot. Для обычной установки он не нужен и усложняет откат.

---

## 2. Промежуточный образ Cudy (обязательный шаг)

Cudy требует, чтобы на роутер сначала попал **подписанный Cudy** образ OpenWrt.
Он лежит в папке Cudy на Google Drive (ссылка на странице устройства OpenWrt):

<https://drive.google.com/drive/folders/1BKVarlwlNxf7uJUtRhuMGUqeCa5KpMnj>

1. Скачайте архив **WR3000S 1.0.zip** и распакуйте его.
2. Внутри — файл вида `cudy_wr3000s-v1-sysupgrade_20251119.bin` (~14,9 МБ).
3. Возьмите **именно .bin**, не .zip.
4. Сверьте размер и MD5 (для сборки 20251119):
   - размер: `14945872` байт
   - MD5: `403e276f74fd29917fd4260294d1a137`

> Файлы для WR3000S/WR3000H/WR3000P от одной даты очень похожи и отличаются одной
> буквой в имени. Всегда сверяйте MD5, чтобы не залить чужой образ.

### Новая флеш-память (код партии 2543 и позже)

С конца 2025 Cudy ставит в WR3000S v1 новую микросхему флеш-памяти ESMT F50L1G41LC.
Такие экземпляры **требуют OpenWrt 24.10.5+** и **свежий промежуточный образ Cudy**
(сборка 20251119 и новее). Старые образы Cudy на них не загрузятся.

Как определить: в серийном номере первые цифры после модели — это `ГГНН` (год-неделя).
`2543` = 2025, неделя 43. Формат бывает разный (`WR3000S2543...` или `S000xxxx2611xxxxx`,
где `2611` = 2026, неделя 11). **Если сомневаетесь — считайте экземпляр новым** и
берите свежий промежуточный образ.

## 3. Шаг 1: заводской образ Cudy

1. Включите роутер, подключите компьютер **кабелем** в любой порт LAN.
2. Откройте веб-интерфейс Cudy: <http://192.168.10.1/>
3. Пройдите мастер первичной настройки:
   - режим: **Беспроводной роутер**;
   - часовой пояс: ваш;
   - WAN: **DHCP**;
   - задайте пароль администратора (у новых прошивок пароля по умолчанию нет).
4. Перейдите в **Advanced Settings → Firmware** (или «Дополнительно → Прошивка»).
5. Загрузите **промежуточный образ Cudy** (тот .bin из шага 2). На экране
   подтверждения обычно виден MD5 — сверьте его.
6. Дождитесь перезагрузки. Wi-Fi после этого не будет — это нормально, работайте по кабелю.

После перезагрузки роутер работает на **Cudy-подписанном OpenWrt**:
- веб-интерфейс LuCI: <http://192.168.1.1/>
- SSH: `ssh root@192.168.1.1` (без пароля)

> **Сейчас — лучший момент для бэкапа уникальных разделов.** Пока запущен
> промежуточный образ, сохраните разделы Factory и bdinfo (калибровка Wi-Fi и
> MAC-адреса). Это уникальные данные, которые не восстанавливаются сбросом:
>
> ```sh
> ssh root@192.168.1.1 'cat /dev/mtd2' > Factory.bin
> ssh root@192.168.1.1 'cat /dev/mtd3' > bdinfo.bin
> ssh root@192.168.1.1 'sha256sum /dev/mtd2 /dev/mtd3'
> sha256sum Factory.bin bdinfo.bin
> ```
>
> Хэши пар файлов должны совпадать. Храните `Factory.bin` и `bdinfo.bin` в надёжном
> месте. На роутере это же делает скрипт `scripts/backup-partitions.sh`.
>
> В PowerShell 5.1 на Windows `>` портит бинарные данные — используйте Git Bash,
> WSL или Linux.

## 4. Шаг 2: официальный образ OpenWrt

Есть два способа.

### Способ А — через LuCI (проще)

1. Откройте <http://192.168.1.1/> (LuCI промежуточного образа).
2. **System → Backup / Flash Firmware**.
3. В поле образа выберите
   `openwrt-25.12.6-mediatek-filogic-cudy_wr3000s-v1-squashfs-sysupgrade.bin`.
4. **Снимите** галочку «Keep settings» — настройки сохранять НЕ нужно.
5. Прошейте и дождитесь перезагрузки.

### Способ Б — по SSH (быстрее для тех, кто любит консоль)

```sh
scp -O openwrt-25.12.6-mediatek-filogic-cudy_wr3000s-v1-squashfs-sysupgrade.bin root@192.168.1.1:/tmp/
ssh root@192.168.1.1
sysupgrade -n /tmp/openwrt-25.12.6-mediatek-filogic-cudy_wr3000s-v1-squashfs-sysupgrade.bin
```

`-O` (заглавная O) заставляет scp использовать старый протокол — OpenSSH 9+ иначе
пойдёт по SFTP, которого в образе по умолчанию нет. Ключ `-n` у sysupgrade означает
«не сохранять настройки».

## 5. Первый вход и базовая настройка

После загрузки официального OpenWrt:

1. Подключитесь кабелем, откройте <http://192.168.1.1/>.
2. Задайте пароль root (System → Administration).
3. Проверьте интернет: **Network → Interfaces**, WAN должен получить адрес по DHCP.
4. Настройте Wi-Fi: **Network → Wireless** (по умолчанию радио выключены).
5. Включите NTP/часовой пояс: **System → System**.

Проверьте версию по SSH:

```sh
cat /etc/openwrt_release      # ожидается 25.12.6
apk --version                 # в 25.12 используется apk
```

## 6. Если что-то пошло не так

- **Сброс конфигурации:** удерживайте кнопку Reset 10 секунд после загрузки.
- **Failsafe:** см. <https://openwrt.org/docs/guide-user/troubleshooting/failsafe_and_factory_reset>
- **Кирпич / не грузится:** загрузчик Cudy умеет принимать только заводскую прошивку
  Cudy по TFTP (кнопка Reset при включении). Порядок: восстановить заводскую Cudy →
  заново повторить шаги 3–4. Инструкция Cudy:
  <https://www.cudy.com/blogs/faq/how-to-recovery-the-cudy-router-from-openwrt-firmware-to-cudy-official-firmware>

Для новых экземпляров (код партии 2543+) при восстановлении берите свежую заводскую
прошивку (2.4.6 и новее), старые 2.3.x на них ставить нельзя.
